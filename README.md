# Profesyonel Yazılımcı Portfolyo Websitesi

Bu proje, profesyonel yazılımcılar için tasarlanmış modern, duyarlı ve koyu temalı bir portfolyo websitesi şablonudur.

## Özellikler

- **Modern Dark Tema Tasarımı**: Profesyonel ve çağdaş görünüm için koyu tema
- **Tamamen Duyarlı Tasarım**: Tüm cihazlarda mükemmel görüntüleme
- **HTML5, CSS3 ve JavaScript**: Saf web teknolojileri kullanılarak oluşturuldu
- **Animasyonlar**: Sayfa geçişleri ve içerik etkileşimleri için pürüzsüz animasyonlar
- **Dinamik Tip Efekti**: Ana sayfada dönen mesajlar için yazı animasyonu
- **Proje Filtresi**: Projeleri kategorilere göre filtreleme özelliği
- **Müşteri Yorumları Kaydırıcısı**: Yorumlar için etkileşimli slider
- **İletişim Formu**: E-posta gönderimi için hazır form
- **Sosyal Medya Entegrasyonu**: Sosyal medya profilleri için bağlantılar
- **Hamburger Menü**: Mobil cihazlar için duyarlı navigasyon

## Dosya Yapısı

```
.
├── index.html          # Ana HTML sayfası
├── css/
│   └── style.css       # Stil dosyası
├── js/
│   └── main.js         # JavaScript işlevselliği
└── img/                # Görseller klasörü
    ├── hero-image.svg  # Ana sayfa görseli
    └── ...             # Diğer görseller
```

## Kullanım

1. Projeyi klonlayın veya indirin
2. İndeksi herhangi bir web tarayıcısında açın
3. Kişisel bilgilerinizi, projelerinizi ve portfolyo içeriğinizi düzenleyin
4. Tasarımı ihtiyaçlarınıza göre özelleştirin

## Özelleştirme

- İsim, meslek, hakkınızda bilgi ve yeteneklerinizi değiştirmek için `index.html` dosyasını düzenleyin
- Renk şemasını değiştirmek için `css/style.css` dosyasında `:root` değişkenlerini güncelleyin
- Yazı tipi, arka plan renkleri ve diğer stil özelliklerini `style.css` içinde değiştirin
